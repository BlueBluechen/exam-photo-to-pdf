# 试卷照片转可打印 PDF

手机拍的试卷，变成能直接打印的 A4。

题目、选项、图形都在原来的位置，页边距也不动。水印没有了，印在题后的答案也没有了——孩子拿到手就能直接做。

会给你两份：一份干净的空白卷，一份留着答案，方便你对。

## 适合

- 手机拍的整页照片、截图、从 PDF 里导出的页面
- A4 或 A4 横向的试卷、练习卷、讲义，黑白彩色都行
- 手里只有答案版，想把它变回空白卷
- 孩子做过一遍，想再打印一份重做

## 不适合

- 拍得模糊、手抖、离得太远的——字看不清，印出来也看不清
- 卷子边缘被裁掉、或者有折角挡着字的
- 想让铅笔、圆珠笔的痕迹消失——擦不掉，会原样保留
- 想改题目、换题、重新排版——它只做净化和打印，不动内容

## 装在哪里

把 `SKILL.md` 和 `scripts/` 放进 agent 的 skills 目录即可。

装好之后，把卷子的照片发给它，说一句「转成可打印的」，剩下的它自己做完。
